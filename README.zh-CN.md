## 📋 关于本仓库

这里汇集 OPEN-TianSuan 社区成员参与发表的卫星系统研究，以及相关技术资料。论文覆盖星上计算、星地通信、在轨遥感处理与卫星网络仿真。

## 📂 仓库结构

| 目录 | 内容 |
| --- | --- |
| [ResearchPapers](ResearchPapers/README.zh-CN.md) | 卫星系统研究论文，按会议和期刊分类。 |
| [TechnicalDocumentation](TechnicalDocumentation/README.zh-CN.md) | 标准、研究报告与参考资料，每条记录类型、发布方与版本信息。 |

## 📁 目录说明

### TechnicalDocumentation — 技术文档（标准等）

面向开源卫星工程的非代码、非数据类资源：研究报告、行业标准、技术规范与工程指南。每条记录名称、类型、发布方、版本或日期以及简要说明。详见 [TechnicalDocumentation/README.zh-CN.md](TechnicalDocumentation/README.zh-CN.md)。
