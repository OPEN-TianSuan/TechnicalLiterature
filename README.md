## 📋 About This Repository

This repository brings together satellite systems research co-authored by OPEN-TianSuan community members and related technical documentation. Topics include onboard computing, satellite-to-ground communications, in-orbit remote sensing, and satellite network emulation.

## 📂 Repository Layout

| Directory | Contents |
| --- | --- |
| [ResearchPapers](ResearchPapers/README.md) | Satellite systems research grouped by conference and journal. |
| [TechnicalDocumentation](TechnicalDocumentation/) | Standards, research reports and reference material, with type, publisher and version recorded for each entry. |

## 📁 Directories

### TechnicalDocumentation

Non-code, non-dataset resources for open-source satellite engineering: research reports, industry standards, technical specifications and engineering guidance. Each entry records the name, type, publisher, version or date and a short description. See [TechnicalDocumentation/README.md](TechnicalDocumentation/README.md).

## 🤝 Contributing

Researchers, developers, students and satellite enthusiasts are welcome. If you know of a paper or document that belongs here, open a pull request or start a discussion.
